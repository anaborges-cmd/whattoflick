# WhatToFlick

Catálogo de filmes e séries desenvolvido como projeto acadêmico da disciplina de Desenvolvimento de Interfaces Web (DIW).

## Objetivo

Oferecer uma interface para catalogar, pesquisar, filtrar, ordenar e classificar filmes e séries, com acesso às informações detalhadas de cada título.

## Funcionalidades representadas

- Catálogo com filmes e séries de exemplo.
- Pesquisa por título.
- Filtros por tipo, gênero, ano de lançamento e nota mínima.
- Ordenação por título, ano e nota.
- Exibição dos detalhes de um título.
- Formulário para cadastro e edição de filmes e séries.
- Controles de exclusão representados na interface.

**Importante:** nesta etapa, os dados são fictícios e a interface é estática. Os controles não realizam operações dinâmicas nem armazenam informações.

## Tecnologias utilizadas

- HTML5 semântico.
- CSS3.
- Git e GitHub.
