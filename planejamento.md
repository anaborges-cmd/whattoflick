WhatToFlick — Planejamento da Etapa 1

1. Objetivo

Desenvolver a estrutura inicial de uma plataforma de catalogação, pesquisa e classificação de filmes e séries, utilizando HTML semântico.

2. Organização da interface

O projeto terá três páginas:

Catálogo (index.html): apresentação dos títulos cadastrados, pesquisa, filtros, ordenação e acesso às ações de detalhes, edição e exclusão.

Detalhes (pages/detalhes.html): informações completas de um filme ou série selecionado.

Cadastro (pages/cadastro.html): formulário compartilhado para cadastro e edição de títulos.

3. Dados dos títulos

Cada título poderá conter:

Nome;

Tipo: filme ou série;

Ano de lançamento;

Gênero;

Diretor ou criador;

Elenco;

Sinopse;

URL do pôster;

Plataforma de streaming;

Duração ou número de temporadas;

Nota de referência.

4. Tecnologias

HTML5 semântico para estruturar as páginas;

CSS para a apresentação visual;

JavaScript reservado para etapas futuras, caso necessário.

Nesta etapa, os dados serão fictícios e as ações de cadastro, edição, exclusão, pesquisa, filtragem e ordenação não precisarão funcionar dinamicamente.

5. Identidade visual

A interface terá estilo cinematográfico, com tema escuro, tons de roxo como cor de destaque e cartões para apresentar os títulos.

6. Funcionalidades futuras

Integração com uma API de filmes e séries;

Cadastro e autenticação de usuários;

Persistência dos dados;

Avaliações pessoais, comentários e listas personalizadas.

Essas funcionalidades não fazem parte do escopo funcional da Etapa 1.

7. Versionamento e publicação

O desenvolvimento será registrado por meio de commits progressivos no Git. Ao final, o projeto será publicado no GitHub Pages e receberá a versão v1.0.0, correspondente à estrutura HTML da Etapa 1.
